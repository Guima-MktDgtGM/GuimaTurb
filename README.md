# GuimaTurb — Seu VTurb Próprio

O **GuimaTurb** é o seu player de VSL proprietário e independente, sem mensalidades e sem depender de plataformas de terceiros.

- `index.html` — Dashboard (biblioteca de vídeos, editor visual, gerador de embed, analytics e segurança)
- `player.html` — O player embedável ultra leve e de alta conversão

## 🚀 Publicar na Vercel
Conecte este repositório no seu painel da Vercel. O deploy é 100% automático.

## 🎬 Como Usar com Vídeo do Cloudflare R2
1. Suba o arquivo MP4 no seu bucket do Cloudflare R2.
2. Copie a URL pública do vídeo (ex: `https://pub-xxxx.r2.dev/video.mp4`).
3. Abra o painel do **GuimaTurb**, adicione o vídeo colando o link do R2.
4. Configure o tempo de pitch do CTA (ex: 1409 segundos para a Frequência 33) e copie o código de embed para a sua página de vendas!
